# 🥬 냉장고 구조대

가족이 냉장고와 식품 보관 장소에 있는 품목, 수량, 기한을 한눈에 확인하고 먼저 사용할 식품을 관리하는 가벼운 웹 앱입니다.

## 실행 방법
1. 저장소에서 `index.html`을 내려받습니다.
2. 파일을 더블 클릭해 Chrome, Edge 등 브라우저에서 엽니다.
3. 식품 이름, 유통기한 또는 소비기한, 수량을 입력하고 등록합니다.

설치, 회원가입, API 키, 서버가 필요하지 않습니다.

## 주요 기능
- 식품 이름, 기한, 수량과 단위 입력
- 등록자, 보관 장소, 메모 기록
- 기한이 가까운 순으로 자동 정렬
- 기한 임박(7일 이내), 오늘까지, 기한 지남 상태 표시
- 식품 정보 수정, 수량 1개 사용, 소진 완료, 삭제
- 품목 검색 및 기한/보관 장소 필터
- JSON 백업 내려받기 및 백업 파일 불러오기
- 모바일 화면에 맞춘 반응형 디자인

## 데이터 저장 및 가족 사용 안내
식품 정보는 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저와 기기에서는 다시 열어도 정보가 남지만, 가족 각자의 휴대전화나 다른 컴퓨터와 자동으로 공유되지는 않습니다. 여러 기기 간 실시간 공유를 하려면 별도의 서버와 사용자 인증 기능이 필요합니다. 현재 버전은 비용과 설정을 줄인 1차 MVP입니다.

브라우저 데이터를 지우거나 다른 브라우저를 사용하기 전에 **백업 파일 내려받기**를 이용하세요. 백업 파일을 불러오면 현재 목록이 백업 내용으로 교체됩니다.

## 기한 상태 기준
- **기한 지남:** 오늘보다 이전 날짜
- **임박:** 오늘부터 7일 이내
- **여유 있음:** 8일 이상 남음

기한 상태는 날짜를 기준으로 한 관리용 표시입니다. 기한이 지난 식품은 상태와 보관법을 별도로 확인하고, 날짜 표시만으로 섭취 가능 여부를 판단하지 마세요.

## 기술
- HTML, CSS, JavaScript
- 브라우저 기본 기능과 Local Storage
- 외부 라이브러리 및 빌드 과정 없음


## 배경음악과 한국어 음성 안내
- 화면의 **음악 켜기** 버튼을 누르면 앱에서 생성하는 잔잔한 멜로디가 재생됩니다. 다시 누르면 음악이 멈춥니다.
- 새 식품을 등록하면 “품목 등록이 완료되었습니다.”라고 한국어로 안내합니다.
- 수량 사용 또는 소진 완료 시 “품목이 처리되었습니다.”라고 안내합니다.
- 수정 및 삭제 시에도 처리 결과를 음성으로 알려줍니다.
- 브라우저의 음성 합성 기능을 사용하므로 인터넷 연결이나 별도 음성 파일이 필요하지 않습니다. 음성은 기기와 브라우저의 한국어 음성 지원 여부에 따라 달라질 수 있습니다.
- 브라우저의 자동 재생 제한 때문에 배경음악은 사용자가 음악 버튼을 직접 눌러 시작하도록 했습니다.
